# Meteo Puls — изчистена 24-часова прогноза

Часовите карти вече съдържат само час, икона, кратко описание, температура и един малък ред за вятър. Премахнат е списъкът с подробни показатели. Иконите са със същия размер като в дневната прогноза; отстоянията, центрирането, цветовете и типографията следват същия стил. Височината остава според съдържанието, без разтягане до височината на 14-дневните карти.

Усещана температура, влажност, количество валежи и морска температура остават в popup. В него вече се показват и часовата вероятност за валежи и наличният AQI. Запазени са табовете с налягане, видимост, облачност и точка на оросяване. Липсващите данни не се заместват с измислени стойности.

Запазени са 24-те часа според местното време на града, хоризонталният скрол, стрелките, BG/EN, двете теми и секцията „Моите места“. Няма промени по базата данни, зависимости или метеорологични изчисления.

## Проверка на настоящата корекция

`npm test`, `npm run lint`, `npm run build` и `git diff --check` са успешни. Build запазва предишното предупреждение за Vercel insights script.

Реален Chromium: 32 комбинации — 1440/768/390/320 px × BG/EN × светла/тъмна тема × наличие/липса на морски данни. Проверени са 24 часови и 14 дневни карти, еднаква височина на часовите карти, липса на хоризонтален overflow, reload, стрелките и отварянето на popup. В таба с водните показатели са проверени количество валежи, вероятност за валежи и морска температура при наличие.

Тестовете използват синтетични API fixtures. Това са действителни браузърни screenshots, но не удостоверяват живи Open-Meteo данни или реален Supabase вход. Предишният достъп до Open-Meteo беше блокиран с HTTP 403. Тестовите стойности не са включени в production приложението. По-ранните проверки на акаунтите не са повтаряни за тази визуална корекция.
