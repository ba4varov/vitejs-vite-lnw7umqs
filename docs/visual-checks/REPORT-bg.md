# Meteo Puls — еднаква структура на часовата и дневната прогноза

Използва се един React компонент `ForecastPeriodCard` и едни CSS правила за ширина, височина, padding, шрифтове, икони и разстояния. Двата панела имат еднаква структура на заглавието и стрелките. На desktop стоят един до друг с еднакви размери и подравнен скрол; на по-тесни екрани са един под друг.

Всяка карта съдържа точно шест категории, в един и същ ред:

1. Час/ден и дата.
2. Метеорологична икона.
3. Кратко описание.
4. Температура.
5. Количество валежи.
6. Скорост на вятъра.

Часовата карта използва стойностите за конкретния час. Дневната използва максималната температура, общите валежи и максималния вятър за деня. Разликата е описана в tooltip и достъпните надписи, които включват и стойността. Датите, дните и описанията следват BG/EN при превключване без reload.

Минималната дневна температура остава в popup. Запазени са усещана температура, влажност, налягане, видимост, облачност, точка на оросяване, UV за дневната прогноза, морска температура и наличният часов AQI. Дневната вероятност за валежи също е добавена в детайлите. Липсващи наблюдения се обозначават с „—“; действителната нула остава нула. Дневните средни показатели се изчисляват само от налични числови наблюдения — липсващи стойности вече не се броят като нулеви.

„Моите места“, сесиите, данните за места и базата данни не са променяни. Няма нови зависимости, нов PR, merge или ръчен deployment.

## Реално изпълнени проверки

- Окончателна Chromium матрица: 32 комбинации (четири ширини × BG/EN × светла/тъмна тема × наличие/липса на морски данни), с пет любими места.
- Във всяка комбинация са измерени двата панела и всичките 38 карти; проверени са точно шестте категории и редът им, 24 часови/14 дневни карти, overflow, reload, стрелките, двата popup изгледа и BG/EN превключване без reload.
- Допълнително са изпълнени 8 проверки за дневните детайли и 8 за липсващи наблюдения. Те са преди окончателното намаляване на отстоянието под мобилните заглавия; данните и popup поведението не са променяни от това CSS уточнение. Размерите в горната таблица са само от окончателната матрица.
- `npm test`, `npm run lint`, `npm run build`, `git diff --check` — успешни. Build има предишното предупреждение за Vercel insights script.
- Добавени са автоматични тестове за часови/дневни стойности и пояснения, реална нула, липсващи стойности и средни наблюдения.

Screenshots са действителни изображения от Chromium с тестови API отговори. Живи Open-Meteo заявки и реален Supabase вход/синхронизация не са удостоверени; предишният достъп до Open-Meteo беше блокиран с HTTP 403. Синтетичните стойности не се използват в production приложението. Проверяван е браузърният скрол, без физически тъчпад/телефон.
